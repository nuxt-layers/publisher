# Changelog

## Unreleased

- **One call composes Publisher** (ADR-0012). `composePublisher({ pool, types, resolveCaller, decide, ... })` fills every port, runs the migrations, checks the composition and answers the scheduled `tasks`. Every `providePublisher*` function, `migratePublisherDatabase` and `checkPublisherComposition` is no longer public. The clock takes a `Date` or an ISO 8601 UTC string; events need no sink until `publish` is given. `@nuxt-layers/publisher/testing` ships `createPublisherFakes()`, refused outside tests.
- **Delete, and reading addresses.** `deletePublisherDocument` (and `DELETE /api/publisher/admin/documents/{id}`, `usePublisher().remove`) removes a document with every version, link, history and redirect, writes `publisher.document-deleted`, and is refused while the new optional policy port (`providePublisherPolicy`, later `policy-map`) holds it (`held`). A fourth permission per type, `publisher.<type>.delete`. `getPublisherAddresses` answers a published document's current and former addresses for `seo` and search.
- **Moderation leaves Publisher** (contract version 2). Removed: `receivePublisherSubmission`, `listPublisherModerationQueue`, `GET /api/publisher/admin/moderation`, `usePublisher().moderation()`, the `moderate` action and `publisher.<type>.moderate` permission, `lifecycle.moderation`, the document's and bundle's `moderation` field, `PUBLISHER_MODERATION_STATES`, the `not-moderated` reason, and the `submission-received` and `submission-moderated` events. Content from people who are not editors is the host's to take in (later `workflow`): it creates an ordinary draft as a service user, and an editor publishes it. The database column stays, unused.
- **Contract version 2.** Publisher no longer decides risk, step-up or approvers. The access-decision port is `decide(user, action, { siteId, type, documentId })` → `{ allowed, reason? }`, and `reason: 'step-up'` answers `insufficient-assurance`. The approval port drops `risk`, `requiredApprovals` and `approverIds`: Publisher publishes only on approval of the exact digest. Removed: `lifecycle.risks`, `PUBLISHER_RISKS`, `PUBLISHER_RISK_FLOOR`, `PUBLISHER_PERSONAL_DATA_RISK_FLOOR`, `riskRank`, `meetsStepUp`, `APPROVAL_FLOOR`, `CRITICAL_FRESHNESS_MINUTES`, `PublisherAssurance` and `Consistency`; the user is `{ identityId }` plus anything the resolver adds, passed to `decide` untouched.
- Documents: terms defined once in the README (user, tenant, site, type, document, version, status, address); "user" replaces "subject" in prose; documents describing today's code say so. Documentation only.
- CI installs with `--no-frozen-lockfile` while the platform is in development, and shows any lockfile drift.
- Toolchain (ADR-0013): Node 26.13.0 (`.node-version`), Corepack 0.36.0 and pnpm 12.16.1; install scripts only for packages in `allowBuilds` (esbuild); CI caches the pnpm store. Development only: hosts' requirements are unchanged.
- Versions reset while the platform is in development: the package is `0.0.0` and the contract version stays 1. The `v1.0.0` tag and release are withdrawn; hosts follow `master`.
- Documents follow ADR-0010: added `RESOURCES.md`, `PLAN.md`, `STORAGE-REGISTER.md` and `capability.json`; the roadmap and the headless migration plan are folded into `PLAN.md`; external links moved to `RESOURCES.md`. Documentation only.
- Moved to the `nuxt-layers` organisation.
- The export bundle format is now `nuxt-layers.publisher` (and `nuxt-layers.publisher.person` for a person's export). Bundles exported as `nuxt4-layers.publisher` no longer import.
- Added `CONTRACT.md`, the one-page host contract for 1.0.0 (ADR-0012 §6). Documentation only.

## 1.0.0 — 2026-10-22

- First release, contract version 1: headless; document types registered by the host; the lifecycle with approval, moderation and scheduling; rich text checked by profile and returned as safe trees; addresses, redirects and links; listings, feeds and sitemap entries; personal data; export and import; a switchable HTTP API and the typed client `usePublisher()`; every document on a site. See the README and `docs/contracts.md`.
